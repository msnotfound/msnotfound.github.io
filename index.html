Fleetorch

One supervisor to run parallel coding agents without shared-state collisions

A cross-platform command center for concurrent agents. Separate Git worktrees, native terminals, and live sessions you can attach to anytime.

Give each agent its own filesystem

Git worktrees keep concurrent changes separated. The supervisor owns process lifecycle while the repository stays clean and reviewable.

Native process, native terminal

Agent definitions live in declarative TOML files. PTY-backed execution preserves full interactive CLI behavior on Unix and Windows.
