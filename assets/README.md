# Project plate provenance

These are original diagram illustrations, not screenshots of live applications or claims of measured performance.

- `fleetorch.webp`: an excerpt captured from the installed `fleetorch --help` command. No agents are spawned.
- `mnemium.webp`: diagram of capture, distillation and hybrid retrieval, based on `mywork/mnemium.txt`, notably `src/core/retrieval.ts`.
- `syntra.webp`: illustrative relationship graph based on the supplier, exposure, evidence, alert and decision concepts in `mywork/syntra.txt`; no live risk data.
- `ghostsignal.webp`: commitment-reveal flow based on `mywork/ghostsignal.txt`; decorative line marks are not hashes or proof output.

Rebuild with `python3 beta/folio-experiment2/assets/build_plates.py` (Pillow and the local Fleetorch executable required). The site itself does not need Python.

Arrow and menu SVGs are Lucide icons. See `LUCIDE-LICENSE.txt`.
